# Claude Code project instructions for br-orakel

Les og følg [AGENTS.md](AGENTS.md). Den er den felles arbeidsavtalen for Codex, Claude Code og andre agenter.

Claude Code kan fungere som hovedagent eller implementasjonsagent. Bruk egen branch/worktree, lever små commits, oppgi tester og følg handoff-formatet i `AGENTS.md`.

Alle brede tilganger er begrenset til hackathon-utviklingen av dette repoet. Alt som berører andre prosjekter, andre GitHub-repositorier, pi-tok utenfor den isolerte `br-orakel`-stacken, pi-amk, krultra.no-produksjon, DNS, backup, secrets eller private filer er fullstendig off limits uten en ny, eksplisitt og konkret godkjenning. Ikke anta at en tidligere tillatelse gjelder for slike handlinger.
